David Mode B 是面向 AI 独立开发者的产品蓝图系统。

它把模糊的产品 Bet 转化为一个统一的产品模型：

```text
Bet -> IA -> Flow -> Low-fi Wireframe -> Scope -> Handoff
```

## 仓库状态

当前分支被刻意清理成一个 documentation-only 基线，用于从第一性原理重新构建真实产品。
此前的 Landing Page、App prototype、Demo runtime、视觉资产、框架配置和桌面封装均已移除。

当前尚未规定应用技术栈，也没有可执行的开发命令。

## 产品不变量

David 不是 chat-first PM bot、通用白板、高保真 UI 生成器、no-code builder 或 coding
agent。核心工作区是统一、constraint-aware 的 Blueprint Canvas：IA 是稳定结构，Flow、
Wireframe、Scope 与 Handoff 都是同一个 canonical Blueprint 的投影。
