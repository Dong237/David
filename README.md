David Mode B is a product blueprint system for AI indie builders.

It turns a fuzzy product Bet into one coherent product model:

```text
Bet -> IA -> Flow -> Low-fi Wireframe -> Scope -> Handoff
```

## Repository State

This branch is intentionally a documentation-only foundation for rebuilding the real
product from first principles. Previous landing pages, app prototypes, demo runtime,
assets, framework configuration, and desktop packaging have been removed.

No application stack or development command is currently defined.

## Product Invariant

David is not a chat-first PM bot, generic whiteboard, high-fidelity UI generator,
no-code builder, or coding agent. Its core workspace is a unified, constraint-aware
Blueprint Canvas in which IA is the stable structure and Flow, Wireframe, Scope, and
Handoff remain projections of one canonical Blueprint.
