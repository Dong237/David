# Quickstart: David Demo Showcase

## Prerequisites

- Node.js `>=22.12` recommended for Vite 8
- npm
- Current Chromium browser

## Install and run

```bash
npm install
npm run dev
```

Open the URL printed by Vite. The configured default is:

```text
http://127.0.0.1:1420/
```

## Quality gates

```bash
npm run typecheck
npm run lint
npm test
npm run build
npm run test:e2e
```

## Recording setup

1. Open the demo at 1440x900 and 100% browser zoom.
2. Activate `Reset Demo`.
3. Follow `docs/product/david-mode-b/demo/03_ai_study_coach_demo_script.md`.
4. Use `Fit view` if the Canvas viewport was changed.
5. Confirm no developer tools, notifications, or debug surfaces are visible.
